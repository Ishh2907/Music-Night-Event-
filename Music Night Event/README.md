# NOOR-E-SHAAM 🎵

An Evening of Music, Sufi & Soul.

## About the Project

NOOR-E-SHAAM is a music night event website designed
using HTML and Tailwind CSS.

The website provides information about the event,
artists, schedule, venue and registration.

## Pages

- Home
- Schedule
- Artists
- Venue
- Register

## Technologies Used

- HTML5
- Tailwind CSS
- Git
- GitHub

## Features

- Responsive design
- Event schedule
- Artist section
- Ticket information
- Venue information
- Registration form
- Mobile-friendly layout
